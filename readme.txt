# Student Performance Analysis (EDA)

## 📊 Project Overview
This project performs **Exploratory Data Analysis (EDA)** on a student performance dataset to understand
how demographic and educational factors influence exam scores.

The analysis focuses on identifying patterns, trends, and relationships
that impact overall student performance.

---

## 🧾 Dataset
- Source: Kaggle – *Students Performance in Exams*
- Records: 1000 students
- Features:
  - Gender
  - Race/Ethnicity
  - Parental level of education
  - Lunch type
  - Test preparation course
  - Math, Reading, Writing scores

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 🔍 Key Analysis Steps
- Data inspection and cleaning
- Feature engineering (`average_score`)
- Univariate and bivariate analysis
- Visualization of score distributions
- Performance comparison across demographic factors

---

## 📌 Key Insights
- Student performance follows an approximately normal distribution.
- Test preparation courses positively impact average scores.
- Higher parental education levels are associated with better performance.
- Gender-based differences are observable in overall student scores.
